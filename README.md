# Disc Compressor ![Disc Compressor Logo](https://github.com/AnthonyTaing897/Disc-Compressor/blob/main/Decals/Disc%20Compress%20Webclip.png)

## Overview ℹ️
Incorporating the use of a website for video input, this tool will allow vidoes greater than 8mb is size to be compress and send to directly to Discord Users. Thus, allowing non-premium users to be able to send videos they might have. I began this project due to being fed up of wanting to send videos to friends or servers but being prevented due to Discord's size restrictions. Rather than going online to compress my videos on possibly malicous websites, I wanted to create my own that relieve this common issue.

## How to use Disc Compressor 🎞️
Currently Disc Compressor still requires small tweaks and improvements before I am statified with it. I will update this read me once this project is suitable for the public.

Disc Compressor is designed as a Discord Bot that you could invite to servers. 
* Using the command **"/request"** prompt the bot to respond with a created session for users to access its website.
* Accessing the website a user will provide a code given that came with the bot's response. 
* Once the code is given, they could then provide videos (current mp4) into the website which will then be sent back to the user compressed, **on Discord**.
